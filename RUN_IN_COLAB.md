# Run in Google Colab

The portfolio notebook is self-contained.

1. Open `notebooks/01_climate_crop_yield_business_analysis.ipynb`.
2. Upload the notebook to Google Colab.
3. Use a normal **Python CPU runtime**. GPU is not needed.
4. Run all cells from top to bottom.
5. Save/download the executed `.ipynb` or export it to HTML if you want a frozen copy with outputs.

The notebook downloads the public source datasets directly at run time, so internet access is required.

You do **not** need to upload the repository ZIP or install the local `src/` package to run the notebook in Colab.
