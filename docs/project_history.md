# Project History

The core business idea was first explored in a university analysis around **2022**.

The 2026 portfolio project is a full rebuild rather than a line-by-line cleanup. The rebuild adds:

- updated public data;
- six crop series;
- matched-cohort long-run comparisons;
- scale-aware detrended climate analysis;
- management variables with coverage checks;
- a time-aware predictive experiment;
- climate-only versus climate + fertilizer ablation;
- strong historical baselines;
- error analysis;
- automated tests and live-data validation;
- a standalone Colab notebook;
- notebook/package parity checking.

The old university notebook is intentionally not included in the repository. It is treated only as historical source material and a style reference.

## Final pre-public audit

Before public release, the project received a separate recruiter-style and engineering audit. That audit specifically looked for:

- claims that were stronger than the data;
- inconsistent units or labels;
- sample-composition problems;
- cross-crop scale problems;
- data leakage;
- weak baselines;
- README/notebook/package drift;
- hand-built figures that were not generated by the validated analysis.

The methodology and portfolio story were updated where those checks found real issues.
