# Project History

This repository is **Version 1.0 of the public portfolio project**.

The core business idea was first explored in a university analysis around 2022.
The 2026 release is not a line-by-line cleanup of that notebook. It is a full rebuild from the ground up with:

- updated public data,
- six crop series,
- stronger climate framing,
- management variables,
- a time-aware predictive baseline,
- error analysis,
- reproducible project structure,
- tests and CI.

The old university notebook is intentionally not included in the main repository.
It is treated as historical source material and a style reference only.
